The plugin registers six hooks in `hooks/register.ts`. `prompt.submit` and `command.run` are also the names of calls, so these hooks run whenever a prompt is submitted or `/model`, `/effort` or `/refine-prompt` is run, whether you do it or other code does. The plugin never makes either call itself.

| Hook                                  | When it acts                                                                                                                                                       | What it may change                                                                                                                                                                                                                                                        |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `session.start`                       | Each session start.                                                                                                                                                | Registers the `/refine-prompt` command.                                                                                                                                                                                                                                   |
| `prompt.submit`                       | Only on the first prompt of a fresh session that is not a slash command, a meta prompt or part of a running turn. Every other submission passes through untouched. | Adds the new-session instruction when you choose **Open in a new session**. When you choose **Refine prompt**, holds the prompt back and puts the rewrite in the prompt box; the prompt text is otherwise never changed. If the hook fails, the prompt is sent unchanged. |
| `turn.step`                           | Each model request while an override or an effort minimum is set.                                                                                                  | Sets the request's model to the one you picked and raises its effort to the minimum when it is lower. Subagent requests are left alone.                                                                                                                                   |
| `command.run` (`/refine-prompt` only) | Each run of `/refine-prompt`.                                                                                                                                      | Reviews the prompt given, asks up to three clarifying questions, and puts the rewrite in the prompt box. Sends nothing.                                                                                                                                                   |
| `command.run` (`/model` only)         | Each run of `/model`.                                                                                                                                              | Leaves the command unchanged. Clears the model override and its part of the status line.                                                                                                                                                                                  |
| `command.run` (`/effort` only)        | Each run of `/effort`.                                                                                                                                             | Leaves the command unchanged. Clears the effort minimum and its part of the status line.                                                                                                                                                                                  |

## Run it from source

All of the plugin's logic is in `hooks/register.ts`, and its tests are in `hooks/register.test.ts`. From a clone of the repository:

```bash
claude --plugin-dir .          # load the plugin from this folder
claude plugin validate .       # check the manifest and hooks module
claude plugin test .           # run hooks/register.test.ts
```

Installed users only get an update when `version` in `.claude-plugin/plugin.json` changes. A `bump-version` workflow does that when a push to `main` changes `hooks/register.ts`, `hooks/hooks.json` or the workflow file itself.
